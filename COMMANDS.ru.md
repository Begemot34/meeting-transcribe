# Команды

| Команда | Что делает |
| --- | --- |
| [`auto`](#auto) | весь конвейер за один запуск: распознавание, спикеры, скриншоты, имена, саммари, HTML и PDF |
| [`asr`](#asr) | распознавание речи и диаризация спикеров, параллельно |
| [`frames`](#frames) | кандидаты в скриншоты и контактные листы для просмотра |
| [`badges`](#badges) | кропы бейджа «Говорит: …» по спикерам |
| [`strip`](#strip) | посекундная лента бейджа для спорного фрагмента |
| [`merge`](#merge) | собрать `transcript.md` и `screenshots/` из рабочей папки |
| [`summarize`](#summarize) | добавить саммари и пересобрать HTML и PDF |
| [`export`](#export) | пересобрать HTML и PDF из `transcript.md`, например после ручных правок |
| [`setup`](#setup) | установить окружение и скачать модели |
| [`serve`](#serve) | работать сервисом: папка-inbox, очередь, веб-интерфейс и HTTP API |
| `doctor [--language X]` | показать, что установлено и где лежат модели; ничего не ставит |
| `install-skill` / `uninstall-skill` | зарегистрировать [SKILL.md](SKILL.md) для агентов / убрать его |

`./transcribe help` печатает тот же список. Для большинства записей хватает `auto`; остальные команды — его
шаги: чтобы переделать один из них вручную или когда агент работает по [SKILL.md](SKILL.md).
Переменные `MT_*` в значениях по умолчанию описаны в [SETTINGS.ru.md](SETTINGS.ru.md).

## auto

```text
./transcribe auto <video> <out_dir> [опции]
```

| Опция | По умолчанию | Что делает |
| --- | --- | --- |
| `--title T` | имя файла | заголовок в транскрипте |
| `--date YYYY-MM-DD` | сегодня | дата в транскрипте |
| `--language X` | `MT_LANGUAGE` | язык встречи |
| `--summary B` | из `setup` | кто пишет саммари в этом запуске: `claude`, `codex`, `opencode`, `local`, `api` |
| `--no-summary` | — | без саммари в этом запуске |
| `--no-names` | — | оставить `SPEAKER_xx`: не искать имена на экране и в тексте |

Промежуточные файлы — в `<out_dir>/.work`: шаги ниже можно перезапускать на ней.

## Шаги

### asr

```text
./transcribe asr <video> <work> [опции]
```

| Опция | По умолчанию | Что делает |
| --- | --- | --- |
| `--language X` | `MT_LANGUAGE` | язык встречи |
| `--max-speakers N` | `10` | верхняя граница числа спикеров |

### frames

```text
./transcribe frames <video> <work> [опции]
```

| Опция | По умолчанию | Что делает |
| --- | --- | --- |
| `--threshold X` | `0.3` | чувствительность к смене кадра; `0.08` — если экран листали |
| `--min-gap S` | `15` | минимум секунд между скриншотами |

### badges

```text
./transcribe badges <video> <work> [опции]
```

| Опция | По умолчанию | Что делает |
| --- | --- | --- |
| `--crop W:H:X:Y` | `360:76:1240:0` | где на кадре бейдж «Говорит: …» |
| `--share-start S` | `70` | с какой секунды идёт шаринг экрана |
| `--per-speaker N` | `6` | сколько кропов бейджа на спикера |
| `--probe T` | — | только сохранить полный кадр на секунде T, чтобы подобрать `--crop` |

### strip

```text
./transcribe strip <video> <work> <start_s> [опции]
```

| Опция | По умолчанию | Что делает |
| --- | --- | --- |
| `--duration S` | `40` | длина ленты в секундах от `start_s` |
| `--crop W:H:X:Y` | `360:76:1240:0` | где на кадре бейдж |

### merge

```text
./transcribe merge <work> <out_dir> --title T --date D [опции]
```

| Опция | По умолчанию | Что делает |
| --- | --- | --- |
| `--title T`, `--date D` | обязательны | заголовок и дата в транскрипте |
| `--speakers file.json` | — | имена спикеров: `{"SPEAKER_00": "Анна"}` |
| `--language X` | распознанный язык | язык заголовков результата |
| `--merge-gap S` | `1.5` | склеивать реплики одного спикера с паузой меньше S секунд |
| `--raw-speakers` | — | оставить метки диаризации как есть: без сглаживания и поправки границ |

### summarize

```text
./transcribe summarize <out_dir> --llm B [опции]
```

| Опция | По умолчанию | Что делает |
| --- | --- | --- |
| `--llm B` | `MT_LLM` | кто пишет саммари: `claude`, `codex`, `opencode`, `local`, `api` ([Саммари](README.ru.md#саммари)) |
| `--model M` | модель CLI по умолчанию; для `opencode` — `MT_OPENCODE_MODEL` | модель для саммари |

### export

```text
./transcribe export <out_dir> [опции]
```

| Опция | По умолчанию | Что делает |
| --- | --- | --- |
| `--no-pdf` | — | только HTML |
| `--width W` | `1280` | ширина скриншотов в HTML, px |
| `--quality Q` | `72` | качество JPEG скриншотов в HTML |

## setup

```text
./transcribe setup [опции]
```

Без опций задаёт вопросы; любая опция их выключает, а не указанное берётся по умолчанию.

| Опция | По умолчанию | Что делает |
| --- | --- | --- |
| `--language ru,en` | `en,ru` | для каких языков скачать модели; первый становится `MT_LANGUAGE` |
| `--model M` | `mlx-large-v3-turbo` на Apple Silicon, иначе `large-v3` | модель распознавания, см. `MT_WHISPER_MODEL` |
| `--device cpu\|cuda` | сохранённое, иначе `cpu` | `cuda`: распознавание и диаризация на NVIDIA GPU (Linux) |
| `--summary B` | сохранённое не меняется | саммари по умолчанию: `claude`, `codex`, `opencode`, `local`, `api`, `none` |
| `--skill` / `--no-skill` | `--no-skill` | запустить `install-skill` или нет |
| `--yes`, `-y` | — | принять значения по умолчанию без вопросов |

## serve

```text
./transcribe serve [опции]
```

Работает, пока его не остановят (Ctrl+C, SIGTERM). Записи, положенные в `<data>/inbox` или загруженные через
веб-интерфейс, встают в очередь; для каждой запускается `auto`, результаты лежат в `<data>/jobs/<id>/`, видны в
веб-интерфейсе и в API. Как это устроено, API и запуск в контейнере: [сервис в контейнере](CONTAINER.ru.md#сервис).
У каждой опции есть переменная `MT_SERVE_*` ([настройки сервиса](SETTINGS.ru.md#сервис)); опция важнее переменной.

| Опция | По умолчанию | Что делает |
| --- | --- | --- |
| `--data DIR` | `MT_SERVE_DATA`, иначе `./data` | папка данных: `inbox/` для новых записей, `jobs/` для результатов |
| `--host H` | `MT_SERVE_HOST`, иначе `127.0.0.1` (в образе `0.0.0.0`) | адрес, на котором слушают веб-интерфейс и API |
| `--port N` | `MT_SERVE_PORT`, иначе `8080` | их порт |
| `--workers N` | `MT_SERVE_WORKERS`, иначе `1` | сколько записей обрабатывать одновременно; каждой нужна память целого запуска |
